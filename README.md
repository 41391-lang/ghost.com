# GhostDM 👻

**O aplicativo de mensagens em que você conversa sozinho.**

GhostDM é uma paródia de aplicativo de direct criada para uma atividade escolar. O usuário conversa com uma personagem fictícia chamada **Luna**. O detalhe inconveniente: ela praticamente nunca responde.

## Planos

| Recurso | Grátis | Premium |
|---|---:|---:|
| Enviar mensagens | Ilimitado | Ilimitado |
| Receber respostas da Luna | Nunca | 1 resposta a cada 10 mensagens enviadas |
| Ver o contador de mensagens | Sim | Sim |
| Histórico salvo no navegador | Sim | Sim |

O Premium não melhora muito a experiência. Ele apenas transforma o silêncio absoluto em silêncio com uma pequena exceção.

## Ideia central
1. O usuário abre uma conversa com Luna.
2. Pode mandar quantas mensagens quiser.
3. No plano grátis, Luna visualiza ou ignora tudo, mas nunca responde.
4. No Premium, a cada décima mensagem válida enviada pelo usuário, Luna manda exatamente uma resposta curta.
5. O contador e o plano atual ficam visíveis para o usuário.

## Como executar

Basta abrir o arquivo `index.html` diretamente em qualquer navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari) ou rodar com um servidor local (ex: Live Server). Não necessita de instalação de pacotes, build ou backend.

## Observação
O projeto é uma simulação local. Não usa Instagram, não acessa contas externas e não envia mensagens reais.
